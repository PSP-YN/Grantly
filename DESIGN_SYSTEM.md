# Grantly Design System

## Brand intent
An education-oriented product that feels credible, focused and accessible—not a generic finance dashboard. Use a clear hierarchy, practical surfaces and restrained motion.

## Three-color palette
| Color | Hex | Purpose |
|---|---|---|
| Academic navy | `#17324D` | Primary text, navigation, structure and trust |
| Warm ivory | `#F6F1E6` | Main background and calm surfaces |
| Terracotta | `#B85C38` | Key highlights, progress and primary accent |

Use neutral border and text tones plus tints/shades derived from the three anchors. Avoid adding purple/blue gradients or unrelated brand hues.

## Typography
- Inter/system sans-serif.
- Readable scholarship titles, short labels and concise supporting text.
- Avoid uppercase body text and unnecessary density.

## Layout
- Desktop sidebar; responsive mobile navigation.
- Content-first scholarship discovery with source and review context visible.
- Use restrained borders and spacing instead of nested card grids.
- Make amount, deadline status, eligibility caveat and source easy to scan.

## Interaction
- Keyboard focus visible.
- Dialogs and controls accessible by keyboard.
- Reduced-motion preference respected.
- Never use color alone to communicate eligibility, deadline or application state.

## Accessibility
The palette and components require contrast testing in actual states. This specification is not a WCAG conformance claim.
