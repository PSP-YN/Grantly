# Grantly Design System

## Brand intent
Education-focused, credible and hopeful. The interface should feel like a well-organized academic workspace rather than a generic finance dashboard. Avoid excessive gradients, glass effects, decorative motion and nested cards.

## Three-color foundation
| Token | Hex | Usage |
|---|---|---|
| Forest / academic ink | `#183D2B` | Primary text, navigation, structural emphasis |
| Parchment / warm ivory | `#F7F4EA` | Page and workspace backgrounds |
| Academic gold | `#C89B3C` | Highlight, progress, key calls to action |

Use muted text, borders and accessibility-focused tints as supporting neutrals/derived tones—not additional brand hues.

## Typography
- Inter / system sans-serif.
- Clear hierarchy, readable scholarship titles, short helper copy.
- Avoid all-caps body copy and overly dense text.

## Layout
- Sidebar on desktop; compact responsive navigation on mobile.
- Main content should prioritize search, source and eligibility information.
- Use consistent spacing, modest border radii and restrained shadows.
- Keep amount, eligibility caveat, deadline status and provider source easy to scan.

## Interaction and accessibility
- Visible keyboard focus.
- Keyboard-operable controls and dialogs.
- Reduced-motion support.
- Do not use color alone for status or eligibility.
- Verify contrast and screen-reader behavior in actual UI states.

This design system is a specification, not a claim of WCAG certification.
