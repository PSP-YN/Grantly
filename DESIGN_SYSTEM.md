# Grantly Design System

## Brand direction
A student-first education funding product: credible, calm, hopeful and practical. Avoid institutional coldness, excessive gradients, cluttered cards and decorative motion that competes with scholarship information.

## Core palette
| Token | Hex | Role |
|---|---|---|
| Ink Navy | `#17324D` | Text, navigation, hierarchy |
| Warm Ivory | `#F4F2EA` | Page surfaces, neutral backgrounds |
| Academic Green | `#2F6B4F` | Primary action, progress, success accents |

Additional tones are tints/shades of these three anchors or neutral line/text colors. Do not introduce a fourth brand color without revisiting the palette.

## Typography
- Inter/system sans-serif for UI, labels, forms and content.
- Strong, concise page headings; scholarship titles should remain easy to scan.
- Use sentence case. Avoid uppercase paragraph copy.

## Layout
- Fixed desktop sidebar with a mobile navigation fallback.
- Content-first responsive main area.
- Keep scholarship metadata, amount, deadline/source state and eligibility review note scannable.
- Prefer clear hierarchy and modest borders over card nesting.

## Interaction
- Visible focus rings.
- Keyboard-accessible controls and dialogs.
- Reduced-motion support.
- Mobile-first form spacing and touch target sizes.
- Never rely on color alone to communicate eligibility or deadline status.

## Data presentation
- Eligibility checks are not award guarantees.
- Unknown information must be visible as unknown/manual review.
- Amount and deadline labels should indicate uncertainty when current notices are not verified.
- Use source links and review notes near scheme details.

## Accessibility
This document is a design specification, not a WCAG conformance claim. Verify contrast, keyboard flow, screen-reader semantics and real mobile layouts as part of QA.
